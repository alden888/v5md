### 1. 生存模式解锁逻辑修复

**问题**: 输入Paid订单后，红屏消失但"单证工具"、"物流"、"全球时钟"等模块依然不可见。

**解决方案**:
```javascript
// workbench-dashboard.js

// 隐藏非关键模块
hideNonEssentialModules() {
    const selectors = [
        '#documents-section',
        '#logistics-section',
        '#global-clock-section',
        '#finance-section',
        '#suppliers-section'
    ];
    
    selectors.forEach(selector => {
        const el = document.querySelector(selector);
        if (el) {
            el.classList.add('survival-hidden');
        }
    });
}

// 显示所有模块
showAllModules() {
    const hiddenElements = document.querySelectorAll('.survival-hidden');
    hiddenElements.forEach(el => {
        el.classList.remove('survival-hidden');
    });
}

// 解除红色警戒时调用
deactivateCriticalMode() {
    // ... 其他逻辑
    this.showAllModules(); // ✅ 关键修复
}
```

**HTML结构保证**:
```html
<!-- 这些模块始终存在于HTML中，默认通过CSS隐藏 -->

</div>
```

### 2. 供应商Tab显示修复

**问题**: 点击供应商Tab后无法正确显示。

**解决方案**:
```javascript
// workbench-suppliers.js

show() {
    console.log('[V14.0 Suppliers] Showing suppliers tab...');
    
    // 1. 隐藏所有其他Tab
    document.querySelectorAll('.tab-content').forEach(tab => {
        tab.classList.add('hidden');
    });
    
    // 2. 显示供应商Tab
    const suppliersTab = document.getElementById('suppliers-tab');
    if (suppliersTab) {
        suppliersTab.classList.remove('hidden');
        this.renderSuppliersList();
    } else {
        console.error('[V14.0 Suppliers] suppliers-tab not found in DOM');
    }
}
```

**Tab切换逻辑**:
```javascript
// Main App Controller in index.html

showTab(tabName) {
    // 隐藏所有Tab
    document.querySelectorAll('.tab-content').forEach(tab => 
        tab.classList.add('hidden')
    );
    
    // 更新导航按钮状态
    document.querySelectorAll('.tab-btn').forEach(btn => {
        btn.classList.remove('border-blue-500');
        btn.classList.add('border-transparent');
    });
    
    // 显示目标Tab
    document.getElementById(tabName + '-tab')?.classList.remove('hidden');
    document.querySelector(`[data-tab="${tabName}"]`)?.classList.add('border-blue-500');
    
    // 特殊处理供应商Tab
    if (tabName === 'suppliers') {
        WorkbenchSuppliers.show();
    }
}
```
